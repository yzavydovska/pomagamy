Jak uruchomić aplikację mobilną
-------------------------------
1. Zainstaluj Node.js (LTS).
2. W terminalu:
     cd mobile
     npm install
3. (Opcjonalnie) skopiuj .env.example → .env i uzupełnij klucze Firebase.
   Bez .env aplikacja startuje w trybie demonstracyjnym.
4. Uruchom:
     npm run start:go
   (podgląd w Expo Go na telefonie Android)
   albo:
     npm run android
   (emulator / urządzenie z Android Studio)

Uwagi
-----
- W paczce nie ma folderu node_modules (instaluje się przez npm install).
- W paczce nie ma pliku .env (sekrety Firebase).
- Ten folder możesz spakować do ZIP i wysłać e-mailem.
